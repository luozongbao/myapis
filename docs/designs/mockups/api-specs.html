📖 Overview

The Fortune Teller API provides random fortune predictions in multiple languages, perfect for entertainment apps and daily motivation services.

🌍 Multilingual

Thai, Chinese, English

🎯 52 Fortunes

Carefully curated predictions

🎲 Random

Cryptographically secure selection

🌐 Base URL

https://example.com/api/fortune-teller/

📡 API Endpoints

GET / Get Random Fortune

Retrieve a random fortune prediction in the specified language.

Example Request

curl "https://example.com/api/fortune-teller/"

Parameters

ParameterTypeRequiredDescription
langstringOptionalLanguage code: "th", "zh", "en"
idintegerOptionalSpecific fortune ID (1–52)

📊 Response Format

Success Response

{ "success": true, "fortune": { "id": 7, "th": "…", "zh": "…", "en": "…" } }

Error Response

{ "success": false, "error": "Fortune file not found" }
